7. Units

Har bar ki width alag unit mein hai. Browser window ka size badlo aur dekho kaun scale hota hai.

px: 300px (fixed, scale nahi hota)
%: 50% (parent ke hisaab se)
vw: 40vw (browser window ki width ke hisaab se)
rem: 20rem (root font size ke hisaab se)
em: 15em (is element ke parent font ke hisaab se)
vh: height 20vh (browser window ki height ke hisaab se)
UnitTypeScalingUse case
pxAbsoluteNoBorders, thin dividers, static sizes
remRelativeRoot fontTypography, padding, margins
