1. Flexbox kya hai?

Flexbox = Flexible + Box. Ye ek CSS layout model hai jo container ke andar ke items ko ek line (row ya column) me arrange, align aur space-distribute karta hai. Container ki size badle to items khud adjust ho jaate hain.

Flex container

Parent element jisme display: flex lagta hai.

Flex items

Container ke direct children. Grandchildren flex item nahi bante.

Main axis

Items ki chalne ki direction (default: left to right). justify-content isi par kaam karta hai.

Cross axis

Main axis ke perpendicular (default: top to bottom). align-items isi par kaam karta hai.

2. Flexbox se pehle: inline-block ka whitespace gap

Cards ko ek line me laane ke liye display: inline-block use hota tha. Par cards ke beech ek chhota gap aa jaata hai. Reason: HTML me do tags ke beech jo space / Enter hota hai, browser use ek text space character maanta hai, aur inline-block elements text ki tarah inline flow me baithte hain, isliye wo space render ho jaata hai (~4px).

3. display: flex lagate hi kya hota hai?

Parent par sirf display: flex likho: saare items ek row me aa jaate hain (flex-direction: row default hai) aur apni content-width jitni jagah lete hain. Free space = container width − saare items ki width ka sum. Neeche light-blue hissa free space hai.

4. justify-content: main axis par spacing

justify-content parent (container) par lagta hai, items par nahi. Ye free space ko items ke beech/aas-paas distribute karta hai.

5. Gap ka math (example)

Maan lo container = 600px, 6 cards × 60px = 360px. Free space F = 240px, n = 6.

ValueFormulaEdge gapBeech ka gap
space-aroundF / n = 240 / 6 = 40 per item (20 + 20)20px20 + 20 = 40px
space-betweenF / (n − 1) = 240 / 50px48px
space-evenlyF / (n + 1) = 240 / 7~34.3px~34.3px

6. Revision: yaad rakhne ki baatein

PropertyEdges par space?Trick
space-aroundHaan, aadhaHar item ke around barabar jagah
space-betweenNahiSpace sirf items ke between
space-evenlyHaan, pooraEvenly: har jagah same
  • justify-content parent par lagta hai, items par nahi.
  • Agar items poori width le lete hain (free space = 0), to space-around/between/evenly ka effect nahi dikhega.
  • Default flex-direction: row hai. column karte hi main axis vertical ho jaata hai aur justify-content bhi vertical chalta hai.
  • Sirf direct children flex items bante hain. Nested elements ko alag se display: flex dena padta hai.
  • justify-content = main axis, align-items = cross axis.
