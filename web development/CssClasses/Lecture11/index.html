2. Box Model

Content → Padding → Border → Margin (andar se bahar).

house
  • Content – text/image; size width & height se
  • Padding – content aur border ke beech ki jagah
  • Border – content + padding ke around line
  • Margin – box ke bahar ki jagah (dashed area)

4. Total Width ki Calculation
