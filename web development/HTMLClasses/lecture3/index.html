05 Boilerplate Code

Boilerplate Code = ek fixed/ready-made structure jo har HTML file mein repeat hota hai — isse baar baar type nahi karna padta.

VS Code→ HTML file banao→ Boilerplate likho→ Browser mein khol kar dekho

07 Line-by-Line Explanation

<!DOCTYPE html>

Browser ko batata hai: "Bhai, yeh HTML5 document hai." Pehle HTML ke versions the (v1, v2, v3...) jo ab deprecated ho chuke hain — aaj current version HTML5 hai, isi ko browser read/render karta hai.

<html lang="en"> ... </html>

Yeh Root Element hai — sab kuch isi ke andar aata hai. lang="en" batata hai page kis language mein hai (Hindi ke liye lang="hin"). Yeh accessibility aur SEO (Search Engine Optimization) ke liye important hai — screen readers aur Google ko language pata chalta hai.

<head> ... </head>

Yeh woh information hai jo page pe dikhti nahi, but browser/search engines ke liye zaroori hai.

meta charset="UTF-8" Character encoding set karta hai — emojis, special characters (₹, é, अ) sab support karta hai.
meta viewport Mobile responsiveness ka foundation — page width device ke barabar, zoom level 1 se start.
title Browser tab pe jo text dikhta hai, wahi hai.
body Yahan sab kuch hota hai jo user actually dekhta hai — text, images, buttons.
