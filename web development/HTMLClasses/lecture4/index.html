Tag & Element

Summary notes by Nishant Sir · HTML fundamentals

tag

What is a tag?

A tag is a keyword written inside angle brackets < >. It tells the browser what type of content follows.

<keyword>

Example — <p> tells the browser: "the content that follows is a paragraph."

element

What is an element?

Element = Opening tag + Content + Closing tag. It's the complete package — not just the tag, but everything it wraps.

<p>Hii Anish</p>

Some tags are self-closing — they don't need a closing tag, like <img /> and <br />.

attribute

What is an attribute?

An attribute is an extra detail or property written inside the opening tag — it gives the tag more information.

<img class="photo" title="My Picture" />

class and title are attributes here — and a single tag can carry multiple attributes at once.

headings

Heading tags — h1 to h6

A heading is a title or subtitle — it tells the reader what a section is about. HTML has six heading levels, <h1> through <h6>, from most to least important.

Rule of thumb — a page should normally have only one <h1>. It represents the page's main title.
<h1>Main Title</h1>
<h2>Sub Heading</h2>
...
<h6>Smallest Heading</h6>

paragraph

The paragraph tag

<p> is used for normal text content — the same way a paragraph works in any essay.

<p>Yeh ek paragraph hai.</p>

div & span

Generic containers

<div> is a generic container — it has no special meaning of its own (unlike <h1>, which means "heading"). It exists purely to group or wrap content, and it's a block-level element.

<span> is also a generic container, but at a smaller scale — it wraps a small piece like a word or phrase, not a whole section. It's an inline element.
