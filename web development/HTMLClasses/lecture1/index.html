01Web Development ke 3 Parts

Har website in teen cheezon se milkar banti hai. Jo teeno handle kar sake, wahi Full Stack Developer hai.

frontend/

Jo user ko dikhta hai — design, layout, buttons, UI.

backend/

Peeche server pe chalne wala logic aur processing.

database/

Jahan sara data — users, posts, files — store hota hai.

02Real Apps mein Frontend vs Backend

Insta aur YouTube jaise apps mein dono parts kaise kaam karte hain, dekho.

instagram
Frontend — reels, likes, comments jo screen pe dikhte hain.

Backend handles: username system, reel processing, uploads.

youtube
Frontend — thumbnails ka grid, video player, comment box.

User "How to make website?" search karta hai → Backend message ko process karta hai → Database se reply aata hai → wapas Frontend pe result dikhta hai.

03Developer Roles

05Static vs Dynamic Websites

Static Website

  • Sabhi users ko same content dikhta hai
  • Example: Restaurant, Business sites

Dynamic Website

  • Har user ko different content milta hai
  • Example: Instagram, YouTube
80–90% of today's websites
