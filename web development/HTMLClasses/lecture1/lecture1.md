## 1. Full Stack Web Development kya hai?

Web development ke 3 main parts hote hain:

- **Frontend** – jo user ko dikhta hai (design, UI)
- **Backend** – jo peeche server pe logic/processing karta hai
- **Database** – jahan data store hota hai

Jab koi developer teeno cheezein (Frontend + Backend + Database) handle kar sakta hai, use **Full Stack Developer** kehte hain.

---

## 2. Frontend vs Backend — Example se samjho

### Example 1: Instagram / YouTube
- **Frontend** → Insta, YouTube ka jo interface dikhta hai (videos, reels, likes, comments)
- **Backend** → Instagram ka username system, reels, Google jaisi cheezein process karna
- Backend flow: **YouTube → "How to make website?" → Frontend banta hai using Backend message processing → Database se reply aata hai**

### Example 2: Restaurant Analogy (Best Example)
Restaurant ke through samjho pura system:

| Restaurant Part | Web Dev Part |
|---|---|
| Table (jaha customer baithta hai) | Frontend |
| Kitchen (jaha khana banta hai) | Backend |
| Store (jaha raw material rakha hai) | Database |

**Flow:** Customer Frontend (table) pe order deta hai (Pasta) → Backend (kitchen) usse process karta hai → Database (store) se ingredients leta hai → wapas Backend banata hai → Frontend pe serve hota hai.

Frontend + Backend + Database = **Full Stack**

## 3. Developer Roles

- **Frontend Developer** → sirf UI/design side pe kaam karta hai
- **Backend Developer** → server-side logic + Database handle karta hai
- **Full Stack Developer** ✅ → Frontend + Backend dono (best/complete role)

## 5. Websites ke Types

### a) Static Website
- Sab users ko **same content** dikhta hai
- Example: Restaurant website, Business website
- Content generally fix rehta hai

### b) Dynamic Website
- Different users ko **different content** milta hai
- Example: Instagram, YouTube
- Aaj ke time 80–90% websites dynamic hoti hain

## 8. Course Roadmap

### Foundation Stage
- **HTML, CSS, JS** → website ka base
- **Tailwind & Bootstrap** → styling frameworks

  - Git = version control **tool** (laptop pe install karna hoga)
